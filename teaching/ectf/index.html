Embedded security, in practice

The Embedded Capture the Flag (eCTF) is MITRE’s attack-and-defend competition for secure embedded systems. Teams design and implement a system against a shared set of requirements, then analyse and attack the other teams’ designs.

The competition brings together secure design, firmware development, hardware-aware security, and offensive testing in a semester-long challenge.
